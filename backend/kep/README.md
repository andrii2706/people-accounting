# Перелік кваліфікованих надавачів для перевірки КЕП

`KEP_VERIFIER=dstu` (за замовчуванням у продакшні) перевіряє кваліфікований підпис відкритою бібліотекою
[jkurwa](https://github.com/dstucrypt/jkurwa) (ДСТУ 4145 з ГОСТ 34.311 і з «Купиною»): підпис саме цього документа,
ланцюжок сертифіката до кваліфікованого надавача з переліку ЦЗО, призначення ключа «підпис», чинність на дату
підпису і статус сертифіката через OCSP надавача.

Перелік (`CACertificates.p7b`) API завантажує сам з `KEP_CA_URL`
(за замовчуванням https://czo.gov.ua/download/certificates/CACertificates.p7b) і оновлює раз на добу.
Якщо сайт не відповідає — бере копію `kep/CACertificates.p7b`, яку кладе в образ деплой. У git файл не потрапляє.

Змінні: `KEP_OCSP=strict` (за замовчуванням: надавач має підтвердити, що сертифікат чинний) або `lax`
(відмова лише якщо сертифікат відкликано; коли OCSP не відповідає — пропускаємо).

Ключі ECDSA / RSA цей режим не перевіряє — для них потрібна бібліотека ІІТ (`backend/iit/README.md`).
